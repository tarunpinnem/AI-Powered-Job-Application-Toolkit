📄 How to Submit Your Resume

Having trouble uploading your resume? This guide will help you successfully submit your resume for analysis.

🎯 Method 1: File Upload (Recommended)

Supported Formats

  • PDF (.pdf) - Most common format
  • Word Document (.docx) - Fully supported
  • Plain Text (.txt) - Always works

File Requirements

  • Maximum file size: 10MB
  • File must not be password protected
  • Document should contain actual text (not just images)
  • Use standard fonts for best results

✏️ Method 2: Copy & Paste Text

How to Copy Text Properly

Open your resume in Microsoft Word, Google Docs, or any text editor
Select all text using Ctrl+A (Windows) or Cmd+A (Mac)
Copy the text using Ctrl+C (Windows) or Cmd+C (Mac)
Paste into the text area on our platform using Ctrl+V or Cmd+V

✅ Do's and Don'ts

✅ DO

  • Use clean, well-formatted documents
  • Save PDFs from Word (not scanned images)
  • Copy text from the original document
  • Use standard fonts (Arial, Times New Roman, etc.)
  • Include actual resume content (experience, education, skills)

❌ DON'T

  • Upload password-protected files
  • Copy raw PDF content or binary data
  • Use image-based or scanned resumes
  • Submit heavily formatted documents with complex layouts
  • Paste content that looks like code or special characters

🔧 Troubleshooting Common Issues

PDF Upload Not Working?

  1. Try opening your PDF in a different PDF viewer
  2. Copy the text manually and paste it instead
  3. Convert your PDF to a Word document (.docx)
  4. Save as plain text (.txt) from your word processor

Getting "Content Not Readable" Error?

  • Make sure you're pasting actual text, not binary data
  • Your resume should include words like "experience", "education", "skills"
  • Include contact information like an email address
  • Ensure the content is at least 50 characters long

File Too Large?

  • Compress images in your document
  • Save as a different format (PDF usually smaller than DOCX)
  • Remove unnecessary formatting or embedded objects
  • Copy and paste the text instead of uploading the file

💡 Pro Tips

  • Best Results: Use a clean Word document (.docx) or copy/paste plain text
  • Formatting: Simple formatting works better than complex layouts
  • Content: Include keywords relevant to your target job
  • Length: Ensure your resume has substantial content (200+ words)
  • Testing: Use our test upload page if you're having issues
